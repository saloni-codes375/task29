# Shoe Store — screenshot-style React assignment

## Run
1. Extract ZIP and open the folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL printed in the terminal.

Home and Payment pages are connected with React Context API. Add shoes, adjust quantities, proceed to payment, choose Cash on Delivery or Credit Card, and return to shopping. This is a front-end demo only; no real payments are processed. Do not enter real card details.
